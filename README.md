# Image Tagging using CNN and TensorFlow

## Shadowfax AI/ML Internship Project

This project is a simple image classification system developed using TensorFlow and CNN.

## Features
- Image Classification
- CNN Architecture
- TensorFlow Implementation
- Multi-Class Prediction

## Technologies Used
- Python
- TensorFlow
- Keras
- NumPy

## Run Project

Install requirements:

pip install -r requirements.txt

Run training:

python train_model.py
